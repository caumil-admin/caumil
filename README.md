# CAUMIL 논문 순위

공유 드라이브 제출 폴더의 개인·팀 논문 원고를 경진대회 엑셀의 **6개 변수**(SOTA 실험 수준, 프레임워크 독창성, HW 시연 유용성, HW-알고리즘 결합도, 라이브 시연 안정성, 발표 전달력)로 채점하고, 가중치 노트북의 **사전함수(닫힌식)** 로 순위를 매긴 페이지입니다.

배포 주소: <https://caumil-admin.github.io/caumil/>

## 구성

- `index.html`, `app.js`, `data/data.js` — 공개용 사이트(순수 HTML·CSS·JS, 외부 의존성 없음). `pipeline/build.py --public --root` 가 만든다.
- `pipeline/` — 원고 내려받기·텍스트 추출·동기화·자동 점검·채점·빌드 스크립트(표준 라이브러리만 사용).
- `data/` — 원고 카탈로그, 6개 변수 기준, 가중치 프리셋, 엑셀 계획서 점수, 계산 결과.
- `eval/<ID>.json` — 원고별 평가 원자료(점수·근거·리스크·인용).
- `site/` — 페이지 템플릿과 스크립트. `docs/WORKFLOW.md` — 새 원고가 왔을 때의 절차.
- `v1/` — 이전 경진대회 전략 사이트(우승 가능성·민감도 분석) 보존본.

원고 원본, 추출 텍스트, 드라이브 목록은 저장소에 올리지 않는다. 카탈로그에는 드라이브 파일 ID 대신 해시만 둔다.

## 로컬 확인

```bash
python -m http.server 4173
```

## 주의

- 적합도(%)는 통계적으로 보정된 우승 확률이 아니라 노트북의 경험 기반 가정을 수치화한 상대 지표다.
- 점수는 hwp·hwpx에서 추출한 본문과 수식만 읽고 매긴 0.05 단위의 정성 평가다. 그림은 근거에 넣지 않았다.
- 계획서 점수는 낙관적 잠정치라 원고 점수와 한 표에 섞지 않는다. 리스크는 점수에 넣지 않고 따로 표시한다.
- 의사결정을 돕는 분석이며 공식 심사 결과를 대신하지 않는다.
